# Web Reconnaissance Scanner

A lightweight Python tool for extracting publicly available information from websites. Built for authorized OSINT (Open Source Intelligence) and penetration testing engagements.

## Features

- Extracts email addresses from webpages
- Identifies phone numbers
- Fast and simple to use
- Generates clean output

## Installation

```bash
pip install requests
```

## Usage

```bash
python recon.py
```
